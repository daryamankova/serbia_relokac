# Релокац — гайды по переезду в Сербию

Статический русскоязычный сайт с двумя клиентскими гайдами:

- подготовка к вылету и первые дни после приезда;
- долгосрочная аренда жилья в Сербии.

Личная первичная анкета из исходного документа намеренно не включена.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
